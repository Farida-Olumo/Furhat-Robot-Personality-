# Furhat-Robot-Personality-
This project explores how different robot personalities can be expressed through conversational behaviours in human-robot interaction.
The system uses the Furhat social robot to deliver personality-driven interactions through scripted dialogue, conversational responses, and variations in communication style.

Project Objectives
Develop distinct conversational personality behaviours for a social robot.
Explore how dialogue and communication style influence robot interactions.
Implement structured interaction sequences.
Investigate personality expression in human-robot interaction.

Key Features
Personality-specific dialogue scripts
Structured conversation flows
Verbal expressions and response variations
Robot interaction control
